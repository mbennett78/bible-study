# Bible Study

A calm personal Bible study app for iPhone and iPad. It is a web app: open it in Safari, tap Share, then **Add to Home Screen**, and it opens full screen like a normal app.

## What works now
- Reader with NASB by default (API.Bible) and an ESV switch (api.esv.org)
- "Open on Bible Gateway" for any chapter
- Picks up where you left off
- Chapter-by-chapter tracker of what you've read, per book and overall
- Text size, light/dark appearance
- Backup file to move progress between phone and iPad

## Keys
Get a free key at [api.bible](https://api.bible) (enable an NASB edition on your plan) and at [api.esv.org](https://api.esv.org). Paste them in **Settings**. They are stored only on your device and are never part of this code.

## Running locally
Any static file server works, for example `python3 -m http.server`, then open http://localhost:8000.
